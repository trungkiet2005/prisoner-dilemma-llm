## Why `appendix.aux` is in the bundle

`main.tex` pulls appendix section/figure numbers in through
`xr`/`\externaldocument{appendix}`, which reads `appendix.aux`. **Overleaf can
never produce that file**: it always compiles with `-jobname=output`, so every
build writes `output.aux`, even if you switch the Main document to
`appendix.tex`. Without an uploaded `appendix.aux`, all 21 cross-references to
the appendix render as `??`.

The `appendix.aux` here is *not* a raw build artefact. `xr` executes every
macro in the file it reads, so a raw aux would drag in `\bibcite` lines
(natbib "multiply defined citations", and with biblatex a risk of pulling
appendix-only references into the main bibliography) plus generic labels like
`LastPage` that collide with `main.tex`'s own. The generator exports only the
21 `\newlabel` entries `main.tex` actually references — 21 of 95.

## After editing `appendix.tex`

The exported numbers are frozen at generation time. If they go stale, **LaTeX
gives no warning at all** — it just prints the old numbers. So rebuild:

```powershell
cd paper\Royal_Society_Interface_Paper
pdflatex appendix ; biber appendix ; pdflatex appendix ; pdflatex appendix
python ..\..\scripts\make_overleaf_bundle.py Royal_Society_Interface_Paper
```

Then re-upload `appendix.aux` (or the whole zip).

## The `latexrelease` guard

`main.tex` and `appendix.tex` both carry

```latex
\IfFormatAtLeastTF{2026-01-01}{\RequirePackage[2025-06-01]{latexrelease}}{}
```

The rollback exists because the local MiKTeX pairs a 2026-06-01 kernel with a
biblatex that will not load under it; without the rollback the local build dies
with four `! Argument of \reserved@a has an extra }` errors.

The guard exists because the *unconditional* form was actively harmful on
Overleaf. There, the kernel is already at the rollback target, so latexrelease
reported "Current format date selected, no patches applied" — and then rolled
five individual packages back anyway:

```
Rollback for package 'graphics' requested -> date 2025-06-01.
   Best approximation is the release introduced on 2019-10-01.
Rollback for package 'amsmath'  -> 2019-04-01
Rollback for package 'array'    -> 2024-06-01
```

Since it patched nothing kernel-side on Overleaf, not loading it there changes
nothing except that graphics and amsmath stay at their 2025 releases. It also
drops 7 of the `Font shape` warnings (37 → 30).

Do not "simplify" this back to a bare `\RequirePackage`.
